Privacy Policy

Effective date: October 11, 2026

This policy explains what data Viral Factory (the "tool") and this website handle, and why. Viral Factory is a private production tool run by one individual creator (the "operator"). It is used to publish the operator's own videos to the operator's own accounts. It is not offered to the public, and it has no user accounts, customers or sign-ups.

1. Who this policy covers

  • The operator, who authorizes Viral Factory to publish to their own TikTok, Instagram and YouTube accounts.
  • Visitors to this website.

Viral Factory does not collect personal data about viewers, followers, commenters or any other platform users.

2. Data obtained through platform APIs

Viral Factory connects only to the operator's own accounts, through official OAuth authorization. Depending on the platform it handles:

Viral Factory does not access or store:

  • followers or following lists;
  • comments or direct messages;
  • other users' videos or profiles;
  • contacts, location or payment data;
  • analytics about individual viewers.

TikTok specifically

  • Viral Factory uses TikTok Login Kit and the Content Posting API (Direct Post), and requests the video.publish scope.
  • The basic profile scope included by Login Kit is not used beyond confirming the account username returned by the Content Posting API.
  • The data received from TikTok is used only to publish the operator's approved videos to the operator's accounts.

3. Content and public data

The videos contain only:

  • information from public sources, such as official statistics, public research and public news headlines;
  • graphics created by the tool.

Public web sources are collected while respecting robots.txt and AI-crawler opt-outs. Each source is stored as an exact copy so that every number can be checked. No private or personal data is collected to make videos.

4. Sharing

  • Data obtained from TikTok, Instagram or YouTube is not sold, rented or shared with anyone.
  • It is not used for advertising.
  • It is not sent to AI service providers. The tool sends AI services only public topic information, such as public headlines and verified public figures, when it uses AI to judge topics.
  • Data is sent to a platform only when publishing to that same platform.

5. Retention and deletion

  • Tokens are kept until the operator removes them or revokes access.
  • Access can be revoked at any time:
    • TikTok: Settings → Security → Apps and services permissions;
    • Instagram: Settings → Apps and websites;
    • YouTube: Google Account → Security → Third-party apps.
  • Deleting the local configuration entry removes the stored token.
  • Local publishing records (post IDs and status) are kept for duplicate prevention and can be deleted by the operator at any time.

6. This website

  • This website is a set of static pages. It sets no cookies, has no forms, and uses no analytics, advertising or tracking scripts.
  • It loads no third-party fonts or scripts.
  • It is hosted on GitHub Pages. GitHub may process technical data such as IP addresses to deliver the pages; see GitHub's privacy statement.

The oauth/callback.html page is used only by the operator during account authorization:

  • It displays the one-time authorization code in the operator's own browser so the operator can copy it into the tool on their computer.
  • It does not store the code or send it anywhere.

7. Security

  • Secrets are never written into source code or published files.
  • Error messages are scrubbed of token values.
  • Uploads go only through each platform's official HTTPS API.

8. Children

Viral Factory and this website are not directed to children and do not knowingly collect data from children.

9. Changes

If data handling changes, this page will be updated and the effective date revised.
